portalFrontEnd
--------------

The file *astroship.html* walks through all features. Live demo: [https://aws-ethereum.github.io/monorpg/](https://aws-ethereum.github.io/monorpg/)

Copy `taketori_js.css` and `templates/` to your project and add:

```html
<link rel="stylesheet" href="taketori_js.css"/>
```

Other repo files are only needed for the demo.
